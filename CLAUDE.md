# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project status

`r3ng-fe-admin-home` is the admin frontend of the RegattaCubed (r3ng) platform. It is
currently a **greenfield Angular 22 scaffold** generated by Angular CLI 22.3.0 — `app.routes.ts`
is empty and there is no feature code yet. Treat this as the starting point: most work here
is building new features rather than modifying existing ones.

## Commands

- `npm start` / `ng serve` — dev server at `http://localhost:4200/` (development config, live reload).
- `npm run build` / `ng build` — production build to `dist/` (default config is `production`).
- `npm run watch` — rebuild on change using the development config.
- `npm test` / `ng test` — run unit tests with **Vitest** (via the `@angular/build:unit-test` builder).
- `ng generate component <name>` — scaffold a component (schematics default to SCSS styles, `app` selector prefix).

### Running a single test

Tests run on Vitest, so filter by name with `-t` or by file path, passed through `ng test`:

```bash
ng test -- -t "should create the app"      # by test name
ng test -- src/app/app.spec.ts             # by file
```

## Architecture & conventions

- **Angular 22, standalone, signal-based.** There are no NgModules. Components are standalone
  and declare their own `imports` (see `src/app/app.ts`). The app is bootstrapped via
  `bootstrapApplication(App, appConfig)` in `src/main.ts`; providers live in `src/app/app.config.ts`.
- **Routing** is centralized in `src/app/app.routes.ts` and wired through `provideRouter(routes)`.
  Add new routes there (lazy-load feature routes via `loadComponent` / `loadChildren`).
- **State** uses Angular signals (`signal()`), not RxJS `BehaviorSubject` patterns, for component state.
- **Component file layout:** each component is split across sibling files — `*.ts` (logic),
  `*.html` (`templateUrl`), and `*.scss` (`styleUrl`). Specs are `*.spec.ts` alongside the component.
- **Styling** is SCSS throughout; global styles in `src/styles.scss`. Note the production
  budget caps: per-component styles warn at 4kB / error at 8kB; initial bundle warns at 500kB / errors at 1MB.
- **Static assets** served from `public/`.

## Code style

Enforced by `.editorconfig` and `.prettierrc`: 2-space indent, single quotes in TypeScript,
final newline, trimmed trailing whitespace. TypeScript is configured strictly (see
`tsconfig.json`: `noImplicitOverride`, `noImplicitReturns`, `noPropertyAccessFromIndexSignature`,
`noFallthroughCasesInSwitch`, plus Angular's `strictInjectionParameters` / `strictInputAccessModifiers`).

## Angular skills

This repo vendors two Angular skills (in `.claude/skills/` and `.agents/skills/`, pinned in
`skills-lock.json`):

- **`angular-developer`** — invoke when writing components, services, HTTP calls, forms,
  routing, signals/reactivity, or for Angular best-practice guidance.
- **`angular-new-app`** — invoke when scaffolding a new Angular application.

Prefer these over generating Angular code from memory, since they track current-version idioms.
